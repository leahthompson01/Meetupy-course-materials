# Module 9 — Background Jobs & Email

## Provided Files

This module includes the email template we'll use for the RSVP confirmation email.

Copy the provided `resources` folder into the root of your Laravel application, preserving the folder structure.

This will add:

- `resources/views/emails/rsvp-confirmation.blade.php`

We'll build the mailable, queued job, and RSVP email flow together during this module.
