# Module 4 — Displaying Events

## Provided Files

These files contain the frontend scaffolding we'll use while displaying our Event data and throughout the rest of the workshop.

Copy the provided `resources` folder into the root of your Laravel application, preserving the folder structure.

This will add/update:

- `resources/js/types/models.ts`
- `resources/js/layouts/events-layout.tsx`
- `resources/js/components/event-card.tsx`
- `resources/js/components/app-sidebar.tsx`
- `resources/js/pages/events/eventForm.tsx`
- `resources/js/pages/events/index.tsx`
- `resources/js/pages/events/show.tsx`

We'll finish wiring the Event data into the `index` and `show` pages together during this module. We'll use the provided `EventForm` component later when we start creating and editing Events.
